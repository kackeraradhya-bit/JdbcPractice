# JDBC MySQL Practice

1. This project demonstrates Java Database Connectivity (JDBC) using MySQL.
2. It establishes a connection between a Java application and a MySQL database.
3. The project uses MySQL Connector/J as the JDBC driver.
4. The database used in this project is `app_db`.
5. The program retrieves student records from the `Student` table.
6. It demonstrates SQL operations using JDBC statements.
7. The `ResultSet` class is used to process retrieved records.
8. The project is developed in Java using Visual Studio Code.
9. MySQL is used to store and manage student information.
10. This project helps understand the basics of JDBC and database connectivity.
